## 二、部署流程

### 步骤1：环境检查（10分钟）

```bash
# 检查Python
python --version    # 应为 3.10+

# 检查网络
ping api.deepseek.com

# 检查pip
pip --version
```

### 步骤2：部署代码（5分钟）

#### 方式A：Git部署（推荐）

```bash
# 克隆代码
git clone https://github.com/air199009/pin-guan-oral.git
cd pin-guan-oral

# 创建虚拟环境
python -m venv venv

# 激活
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

#### 方式B：U盘部署（无网环境）

1. 在有网环境打包：`pip download -r requirements.txt -d packages/`
2. U盘拷贝整个项目 + packages/ 目录
3. 客户电脑：`pip install --no-index --find-links=packages/ -r requirements.txt`

### 步骤3：配置API Key（3分钟）

```bash
# 复制配置模板
copy .env.example .env

# 编辑
notepad .env
```

填入客户的大模型API Key：

```ini
# 推荐DeepSeek（便宜）
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxx

# 或通义千问
QWEN_API_KEY=sk-xxxxxxxxxxxx
```

### 步骤4：放置模型权重（5分钟）

把训练好的模型放到 `models/` 目录：

```
models/
├── yolov8n_teeth.pt     # 牙齿检测模型
└── yolov8n_disease.pt   # 病灶识别模型（可选）
```

### 步骤5：启动服务（2分钟）

```bash
python app.py
```

成功启动后会显示：

```
🚀 正在启动 DentalPilot AI...
📍 访问地址: http://127.0.0.1:7860
✅ 加载牙齿检测模型: models/yolov8n_teeth.pt
```

### 步骤6：浏览器测试

打开浏览器，访问 `http://127.0.0.1:7860`

1. 上传一张测试影像
2. 选择影像类型
3. 点击"开始AI分析"
4. 检查输出是否正常

### 步骤7：创建开机自启（Windows）

创建 `start_dentalpilot.bat`：

```bat
@echo off
cd /d "C:\dentalpilot\pin-guan-oral"
call venv\Scripts\activate
python app.py
```

放到 Windows 启动文件夹：
- `Win+R` 输入 `shell:startup`
- 把 `start_dentalpilot.bat` 复制进去

### 步骤8：内网穿透（可选，公网访问）

如果客户需要外网访问：

```bash
# 方案1：cpolar（国内，免费）
cpolar http 7860

# 方案2：frp（自建）
frpc -c frpc.ini

# 方案3：花生壳
```

## 三、医生培训（30分钟）

### 培训内容

1. **基础操作**（10分钟）

## 六、常见问题FAQ

### Q1：客户电脑没有外网怎么办？
A：用API代理服务（Cloudflare Workers免费版），客户配置代理URL即可。或本地下载Qwen2.5-1.5B模型（1.5GB）完全离线。

### Q2：API key谁出钱？
A：客户自付（50-200元/月）。我们不背API费用。

### Q3：模型多久更新一次？
A：每季度一次大版本，每月小优化。客户无感升级。

### Q4：医生反馈数据归谁？
A：脱敏后归我们，用于模型优化。原始影像仍归客户。

### Q5：能进医院招标吗？
A：暂时不能（无三类证），但可作为"数字化升级项目"采购。

### Q6：竞品对比？
- 牙医管家睿知影：云端，1.3万/4年，依赖外网
- 领健AI看牙：云端，1.5万/年，依赖外网
- **我们的优势**：本地部署，3万一次性，**不依赖外网**（医院内网可用）

### Q7：客户用一段时间想换其他系统？
A：合同写清楚数据归属，反馈数据脱敏后归我们。客户原始数据100%归还。

### Q8：模型训练数据哪来？
A：公开数据集（DENTEX等）+ 客户授权的真实数据（脱敏）。客户数据永远不外传。
